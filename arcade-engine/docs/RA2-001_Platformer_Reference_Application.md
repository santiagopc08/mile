# RA2-001 — Platformer Reference Application

Version: 1.0 (Draft)  
Status: Draft  
Category: Reference Application

---

## Purpose

Platformer is the second Reference Application.

Its purpose is validating character-centric gameplay.

Unlike Hill Climb, this application focuses on animation,
interaction and AI.
