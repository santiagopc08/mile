# RA4-001 — Sandbox Reference Application

Version: 1.0 (Draft)  
Status: Draft  
Category: Reference Application

---

## Purpose

Sandbox validates runtime scalability,
dynamic world editing,
streaming,
persistence
and tooling.

Unlike previous applications,
the player creates the world.

---

## Runtime Coverage

- Streaming
- Persistence
- World Editing
- Large Worlds
- Undo
- Redo
- Selection
- Placement
- Serialization
- Save
- Loading
- Assets
- Plugins

---

## Gameplay Loop

```text
Explore
  ↓
Collect Resources
  ↓
Build
  ↓
Modify
  ↓
Save
  ↓
Reload
  ↓
Continue
```
