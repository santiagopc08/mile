# RA-020 — Developer Console

Version: 1.0 (Draft)  
Status: Draft  
Category: Development

---

## Purpose

Provide runtime inspection and debugging tools.

The console SHALL execute only developer commands.

---

## Commands

- `help`
- `clear`
- `quit`
- `restart`
- `reload`
- `pause`
- `resume`

---

## Gameplay Commands

- `spawn coin`
- `spawn fuel`
- `refill fuel`
- `set speed`
- `teleport`
- `flip vehicle`
- `repair vehicle`

---

## Physics Commands

- `gravity`
- `friction`
- `torque`
- `mass`
- `suspension`

---

## Camera Commands

- `zoom`
- `follow`
- `shake`
- `reset`

---

## Debug Commands

- `show collisions`
- `show fps`
- `show events`
- `show queries`
- `show scheduler`

---

## Asset Commands

- `reload assets`
- `list assets`
- `validate assets`

---

## Validation

- Autocomplete
- History
- Error reporting
- Permission control
