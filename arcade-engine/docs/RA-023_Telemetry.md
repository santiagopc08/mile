# RA-023 — Telemetry

Version: 1.0 (Draft)  
Status: Draft  
Category: Analytics

---

## Purpose

Collect anonymous gameplay metrics.

Telemetry SHALL never affect gameplay.

---

## Metrics

- Distance
- Coins
- Fuel Usage
- Crashes
- Session Duration
- Average Speed
- Maximum Speed
- Pause Count
- Restart Count

---

## Performance Metrics

- FPS
- Frame Time
- Memory
- GPU Time
- CPU Time
- Asset Loading

---

## Events

- Session Started
- Session Ended
- Crash
- Fuel Empty
- Checkpoint
- Settings Changed

---

## Privacy

- Player Identity SHALL NOT be required.
- Telemetry SHALL be optional.

---

## Validation

- Minimal overhead
- Reliable delivery
- Offline buffering
