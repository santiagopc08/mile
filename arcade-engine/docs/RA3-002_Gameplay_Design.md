# RA3-002 — Gameplay Design

Version: 1.0 (Draft)  
Status: Draft  
Category: Reference Application

---

## Core Gameplay

```text
Prepare
  ↓
Place Towers
  ↓
Start Wave
  ↓
Defend Base
  ↓
Earn Currency
  ↓
Upgrade
  ↓
Repeat
```

---

## Player Actions

- Place Tower
- Sell Tower
- Upgrade Tower
- Start Wave
- Pause
- Speed Up

---

## Failure

- Base Health = 0

---

## Victory

- Survive Every Wave

---

## Metrics

- Wave
- Enemies Killed
- Currency
- Lives
- Damage
- Accuracy
