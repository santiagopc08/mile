# PS-007 — Entity Model

Version: 1.0 (Draft)  
Status: Draft  
Category: Platform Specification  

---

## 1. Introduction

This specification defines the Entity Model of ORBIT Arcade Platform.

Entities represent identifiable runtime objects.

Entities provide identity.

Entities provide ownership.

Entities provide lifetime.

Entities do not define behavior.

Actors are a specialized form of Entity.

---

## 2. Scope

This specification defines:

- Entity definition
- Entity ownership
- Entity identity
- Entity lifecycle
- Entity hierarchy

This specification does not define:

- Components
- Systems
- ECS storage
- Rendering
