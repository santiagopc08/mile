# RA-013 — HUD & UI

Version: 1.0 (Draft)  
Status: Draft  
Category: Presentation

---

## Purpose

Display gameplay information.

HUD SHALL never access gameplay state directly.

HUD SHALL consume Presentation Models only.

---

## Screens

- Splash
- Main Menu
- Gameplay
- Pause
- Settings
- Game Over

---

## Gameplay HUD

- Fuel Gauge
- Distance
- Coins
- Speed
- FPS (Debug)

---

## Pause Menu

- Resume
- Restart
- Settings
- Exit

---

## Game Over

- Distance
- Coins
- Restart
- Exit

---

## UI Events

- Pause
- Resume
- Restart
- Exit

---

## Animations

- Fade
- Scale
- Slide
- Counter Animation

---

## Validation

- No gameplay dependency
- 60 FPS animation
- Responsive layout
- Controller support
